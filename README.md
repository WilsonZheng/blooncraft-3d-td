# 🎈 气球防线 3D · BloonCraft 3D TD (v3.0)

一款基于 **Three.js + WebGL (HDR UnrealBloom) + Web Audio API** 纯前端打造的 3D 策略塔防网页游戏（致敬 Bloons TD 并融合 Roguelike 秘宝构筑、双塔神装合体、狂暴超载与跨局永久科技）。经过 **50 轮自动化 AI 模拟自测与画质/手感闭环调优**。

## ✨ 核心特色 (v3.0)

- **🎨 次世代清新玩具风 3D 画面与动态地图演进**
  - **3 张特色立体地图**：翠绿风车牧场、熔岩黑曜峡谷、极光冰封雪原，每张地图随波次推进（W10 / W20）触发三阶段地貌觉醒与昼夜光影演进，搭配实时 3D 天气粒子场（微风、骤雨、熔火余烬、暴风雪）。
  - **17 种精细 3D 气球与巨型飞艇 Boss**：迷彩、再生、紫电护盾、铁皮、斑马、彩虹、陶瓷，以及带旋转螺旋桨与装甲细节的 `MOAB`、`DDT 幽灵隐形艇`、`BFB 毁灭红艇`、`ZOMG 翡翠泰坦舰` 与 `黄金宝藏艇`。
- **🗼 8 大特色鲜明的专属机制炮台 + 神装合体 & 巅峰升星**
  1. **🎯 飞镖射手**：每第 5 次射击必暴击，且所有暴击飞镖自动弹射追击邻近目标。
  2. **⚙️ 八方钉塔**：锯齿飞刃附加持续流血；每第 4 次攻击迸发大范围【熔火日冕】新星。
  3. **💣 重炮轰炸塔**：高抛榴弹落地必爆，将普通气球沿路线震退并附加碎甲易伤；每第 4 发发射巨型凝固汽油弹。
  4. **❄️ 极寒冰晶塔**：对已冰封目标触发高额【碎冰斩杀】，每第 3 次脉冲额外射出贯穿飞艇的极寒冰枪。
  5. **🥷 暗影忍者**：手里剑叠加暗影死印，满 4 层触发十字紫电【瞬影斩】按最大生命比例重创飞艇。
  6. **🔭 苍穹狙击塔**：全图无限射程，击杀目标额外掉落猎头赏金，穿甲弹道震伤后方气球群。
  7. **⚡ 雷霆电弧塔**：连锁闪电跳跃，每第 3 次雷击在航道生成逆流漫游的【3D 等离子球形闪电】。
  8. **🏛️ 黄金信标工坊**：每波产金与空投金币，周期性释放黄金战鼓波赋予友军 `+18%` 暴击并号令最高阶主力塔立即齐射。
  - **🧬 双塔神装合体 & 🌟 巅峰升星**：满级塔可吞并同系塔腾出宝贵空位进阶神装，并支持无限紧凑升星（`★1 ~ ★5`）。
- **🔥 爽感突破系统（v3.0 新增）**
  - **🔥 狂暴超载时刻 (Fever Overdrive)**：连续击破气球蓄满超载槽，自动触发 8 秒黄金狂暴（全军攻速 `+40%`、暴击率 `+20%`、击破赏金 `+25%`、BGM 切入高速狂暴变奏）。
  - **⚔️ 恶魔悬赏契约 (Elite Bounty Contract)**：每波发兵前可自选签署高风险契约，本波敌军强化但通关享 `+65%` 波次赏金、双倍指挥官经验与额外 `+2 💎 星辉晶石`。
  - **💎 星辉永久科技馆 (Meta Tech Tree)**：跨局永久保留的星辉晶石可升级初始军费、圣盾生命、暴击倍率、星轨大招冷却与统帅学识。
  - **🃏 战略秘宝三选一 (Roguelike Augment Draft)**：里程碑波次、指挥官升级与击破黄金宝藏艇触发全息秘宝抽卡（支持卡池刷新与战场自动时停）。
- **🎵 动态多轨交响电子配乐 & 独立炮台音效**
  - 纯 Web Audio API 实时合成（零外部音频文件依赖）：3 大地图专属调式旋律 × 4 档动态战斗强度（备战 / 交战 / 飞艇 Boss / 狂暴超载），内置 `DynamicsCompressor` 母带防爆音压缩与 8 种炮台专属开火音效。
- **💾 完整战局存档与 ⚙️ 音画设置中心**
  - 每波结束自动存档 + 3 组手动存档槽 + `BLOON3D:...` Base64 跨设备存档码一键复制/导入。
  - 支持主音量 / BGM / SFX 独立滑块、HDR 辉光开关、震屏开关、暴击飘字开关、天气粒子开关、抽卡自动时停及 **自动磁吸拾取金币与空投箱**。

## 🚀 本地运行与构建

```bash
npm install
npm run dev      # 启动本地开发服务器
npm run build    # 生成生产环境静态包 dist/
```

```bash
ROUND=50 node tests/harness.mjs
```
